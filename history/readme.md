# 강의교안 웹뷰 히스토리

대전일자리경제진흥원 임직원 AI 실무교육 「기관 업무에 적용하는 AI 활용·업무자동화 실습」 강의교안(`index.html`)의 버전 기록입니다.

## 관리 규칙

- 관리 대상은 `index.html` 하나입니다. 별도 페이지(`pages/`)·css·js·샘플 파일은 보존하지 않고, 변경이력에만 기록합니다.
- 작업한 날짜 단위로 버전을 하나씩 올립니다(+0.001).
- 그날 작업이 끝나면(23:55 기준) 또는 다음 작업을 시작하기 전에, 직전까지의 `index.html`을 `index_v0.00N.html`로 이 폴더에 보존합니다.
- 보존 파일은 기록용 사본입니다. 수정은 항상 상위 폴더의 `index.html`에서 합니다.
- 보존 파일은 `history/` 안에 있어 css·js·이미지 경로가 맞지 않으므로 화면이 깨져 보일 수 있습니다. 내용 비교용으로 사용합니다.
